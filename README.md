This notebook prepares a Nairobi PM2.5 training dataset for machine learning. It starts by defining a data-quality weighting scheme for sensor readings. A half-normal function converts the number of valid hourly observations in a day (12 to 24 hours) into normalized weights from about 0.48 to 1.0, so days with more complete data count for more. It then examines the predictor variables, which are satellite (VIIRS), meteorological and raster covariates, in three ways. A Pearson correlation heatmap shows linear relationships. Mutual information scores rank how strongly each predictor relates to daily average PM2.5, including non-linear relationships. A stepwise Variance Inflation Factor (VIF) analysis removes collinear features in cumulative steps: wind speed, VIIRS M05, then surface pressure, with PBL height kept. The final step exports a cleaned CSV with the redundant variables dropped, ready for modelling.
